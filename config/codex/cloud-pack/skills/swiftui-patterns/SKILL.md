# SwiftUI review

Instruction ID: `skill/swiftui-patterns`.
Requires: Apple SDK and project UI tests for execution.

Follow project-local AGENTS.md and higher-priority instructions. Use the existing task authorization. If a required tool or decision is absent, report BLOCKED for that step and continue independent authorized work.

## Procedure

Review view identity, observable state ownership and main-actor mutations. Keep derived state consistent and handle loading/errors explicitly. Inspect navigation, accessibility labels and environment dependencies. Run available UI/unit tests only on a supported SDK; provide code findings when Cloud cannot execute the UI.

## Completion report

Report the input/scope, inspected paths, concrete output or findings, executed checks with exits and case counts, and unavailable dependencies. Separate local evidence from provider invocation.
