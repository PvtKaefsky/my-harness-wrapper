# Spring Boot TDD

Instruction ID: `skill/springboot-tdd`.
Requires: project JDK, JUnit and configured test dependencies.

Follow project-local AGENTS.md and higher-priority instructions. Use the existing task authorization. If a required tool or decision is absent, report BLOCKED for that step and continue independent authorized work.

## Procedure

Start with a failing JUnit case at the narrowest meaningful unit or slice. Use isolated integration resources and verify validation, authorization and transaction failure. Implement minimally, rerun RED to GREEN and the affected suite. Respect the project coverage threshold and report missing test-container support.

## Completion report

Report the input/scope, inspected paths, concrete output or findings, executed checks with exits and case counts, and unavailable dependencies. Separate local evidence from provider invocation.
