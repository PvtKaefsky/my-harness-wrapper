# Requirements

One testable line per behavior a user or caller can observe. The live probe on pull request #107, recorded in `docs/environment.md` under Pull request activity, the probe on pull request #114 and `PvtKaefsky/autofix-probe`, and the probes on pull request #112, recorded in the same section, test the rows marked probe under Pull request comments; the repository's test scripts cannot drive a session. `scripts/test-pr-comment-rules.sh` checks the section's text only.

## Attribution guard

| Requirement | Test |
| --- | --- |
| A `gh api` write to a `/pulls` or `/issues` endpoint whose `--input <path>` or `--input=<path>` file carries an attribution line, in its raw text or in a decoded JSON string value, is blocked with exit 2 and the matched line; `--input -` reads no file. | `scripts/test-attribution-guard.sh`, the `--input` cases |
| An `--input` file over 1 MiB, or one starting with `{` or `[` that `jq` cannot parse, is blocked with exit 2 as not checked. | `scripts/test-attribution-guard.sh`, the depth-limit and over-1-MiB `--input` cases |
| An attribution line that follows a bare carriage return, in a command, a body file, a decoded `--input` string or an MCP tool string, is blocked with exit 2 and the matched line. | `scripts/test-attribution-guard.sh`, the carriage-return cases |
| A `mcp__github__create_pull_request` response body whose attribution line follows a bare carriage return exits 2 with the resend instruction. | `scripts/test-attribution-guard.sh`, the create-response carriage-return case |
| A `gh` write command, or a body file, carrying an attribution line is blocked with exit 2 and `matched line ->` at any size, wherever the `gh` line or the match sits; a large command that is not a `gh` write exits 0. | `scripts/test-attribution-guard.sh`, the 140,000-byte, 396 KB and 900,000-byte cases |
| A line that starts, after optional whitespace and in any letter case, with `Assisted-by:`, `Generated-by:`, `AI-assisted:` or `Written-by:` and then carries the word `Claude` or `Anthropic` is blocked by the guard with exit 2 and the matched line, and refused by the `commit-msg` hook; such a line naming anyone else, and one of those trailer words in the middle of a line, pass both. | `scripts/test-attribution-guard.sh`, the trailer-word cases and their permitted neighbours; `scripts/test-hook-forwarding.sh`, M1 to M6 |
